# 3D models collection

A list of open-source software for 3D models web-publication.

## Single 3D models

- **3DHOP**: 3DHOP (3D Heritage Online Presenter) is an open-source framework for the creation of interactive Web presentations of high-resolution 3D models, oriented to the Cultural Heritage field. <br>
  [Official website](https://3dhop.net/) <br>
  Screenshots: <br>

  More info: <a href="notes/3dhop.md">bibliography, webography and field use</a> <br>

  -***3DHOP X-Ray Tool***: Arc-Team extension for 3DHOP to visualize the inner structure of a 3D model through its semi-transparent outer surface, developed during the 3D documentation of the Similaun Mummy (Ötzi); version 2.0 adds a real-time x-ray intensity slider and a measure tool calibrated in millimetres. <br>
    [Official website](https://github.com/lucaarcteam/3dhop_x-ray_extension) <br>
